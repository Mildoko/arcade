# 申请免费域名 `arcade.is-a.dev`

> 现状：站点已经上线在 <https://mildoko.github.io/arcade/>（HTTPS、CDN、自动部署都通了）。
> 这一步只是把地址换成更好看的 `arcade.is-a.dev`，**没有它站点也是能用的**。
>
> 查过了：`arcade.is-a.dev` **还没被占用**（register 仓库里没有这个文件）。

## ⚠️ 先看这一条

is-a.dev 官方 README 明确写着：

> Do not use AI to generate your request, it **WILL** always get it wrong and will delay you getting a domain.

所以**这一步我不替你提交**。我把要填的内容、要点的位置、合并后要改的配置全部写在下面，你自己点提交（内容很短，照抄即可）。

## 提交（约 3 分钟）

1. Fork 官方仓库：<https://github.com/is-a-dev/register/fork>
2. 在你的 fork 里新建文件 `domains/arcade.json`，内容**逐字照抄**：

```json
{
  "owner": {
    "username": "Mildoko"
  },
  "records": {
    "CNAME": "mildoko.github.io"
  }
}
```

3. 提 PR 到 `is-a-dev/register` 的 `main` 分支。标题写 `Register arcade.is-a.dev` 就行。
4. 等审核（通常几小时到几天）。被要求改就改，别关 PR 重开。

> 字段是 `records`（复数），不是 `record` —— 这是官方 GitHub Pages 指南里的写法。
> 如果 PR 模板还要求 `description` / `repo` 字段，按模板填：description 写一句站点是什么，repo 填 `https://github.com/Mildoko/arcade`。

## 合并之后（我来做，你只要说一声）

1. 到 <https://github.com/Mildoko/arcade/settings/pages> → Custom domain 填 `arcade.is-a.dev` → Save
2. 等 DNS 生效（几分钟），勾上 **Enforce HTTPS**
3. 我跑一条命令把全站改到根域名：

```bash
node tools/set-domain.mjs arcade.is-a.dev   # 同时改 url / basePath / customDomain
node build.mjs --clean && node tools/check.mjs && node tools/check-links.mjs
git push                                    # Actions 自动重新部署
```

改完之后：
- 正式地址 `https://arcade.is-a.dev/`（根路径，不再带 `/arcade`）
- canonical / sitemap / og:image 全部跟着变成新域名
- 旧的 `mildoko.github.io/arcade/` 会自动 301 到新域名

## 为什么不选别的免费方案

| 方案 | 结果 | 结论 |
|---|---|---|
| Freenom（.tk/.ml/.ga/.cf/.gq） | 2023 年起停止新注册，站点基本停摆 | ❌ 别碰 |
| `eu.org` | 免费、永久，但**人工审核几周～几月** | 可以并行申请，当备份 |
| `js.org` | 需要项目"与 JS 生态相关"，易被拒 | ⚠️ 不确定 |
| `xxx.pages.dev` / `xxx.vercel.app` | 立刻可用，但要注册对应平台账号，且要搬托管 | ⚠️ 不如现在这套 |
| **`arcade.is-a.dev`** | 免费、HTTPS、只认 GitHub Pages 常见配置 | ✅ 就用这个 |

## 以后想换成自己的域名

随时可以，一条命令：

```bash
node tools/set-domain.mjs yourdomain.com
```

然后到域名商的 DNS 加 4 条 A 记录（185.199.108.153 / .109.153 / .110.153 / .111.153）或一条 CNAME 指向 `mildoko.github.io`。`.xyz` / `.top` 首年一般 $1–3，续费才是真成本。
